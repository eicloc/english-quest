# Generated dictionary data

This directory is generated by `scripts/import-dictionary.mjs` and uses schema
version 1. `index.json` contains only search metadata; full `DictionaryEntry`
objects are split by first letter under `shards/`.

`pronunciation-audio.json` is a separate schema-versioned manifest of selected
Wikimedia Commons recordings. It stores only exact US or UK accent matches and
includes the source page, author and license for each retained recording. Audio
files remain hosted by Wikimedia and are loaded only for the selected word.

The build contains the fixed 2,809 ranked NGSL entries plus four library-only
supplemental quest terms. Supplemental terms use `ngslRank: 0` and `band: 0`,
so they never enter the seven NGSL learning stages.

Do not edit generated JSON by hand. Source versions, dates, SHA-256 hashes and
license identifiers are in `sources.json`; human-readable notices are in the
repository root `THIRD_PARTY_NOTICES.md`.
